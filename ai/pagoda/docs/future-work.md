# Future work

Candidates for expanding the workspace, subject to a product decision.

- **Extension interactions:** graphical controls for Pi dialogs and tools such as
  `ask_user_question`.
- **Profile selection:** choose an existing account profile through the desktop, using Pi's profile
  system.
- **Credentials:** manage credentials through desktop screens.
- **History tree:** explore conversation branches through a richer graphical view.
- **Terminal:** work with an embedded terminal.
- **Files:** browse and edit files within the workspace.
- **Distribution:** install and run the app through installers and distribution packages.
